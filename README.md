# FormulaFeed

FormulaFeed is an iOS application in development that allows users to track the Formula One season's races and standings. This app is built entirely using Swift.

## Features

- **Race Tracking**: Get detailed information about each race in the current season, including dates, locations, and results.
- **Standings**: View the latest standings for both drivers and constructors.
- **Notifications**: Stay updated with live notifications about upcoming races and changes in standings.

## Installation

To run this project locally, you will need to have Xcode installed on your machine.

1. Clone the repository:
   ```bash
   git clone https://github.com/JGrater/FormulaFeed.git
2. Open the `FormulaFeed.xcodeproj` file with Xcode.
3. Build and run the project on your preferred device or simulator.
